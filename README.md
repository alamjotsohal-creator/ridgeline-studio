# Ridgeline Studio

3D roof visualizer for roofing consultations. Enter a customer's address and it builds the house from its OpenStreetMap building outline over Esri satellite imagery. You can then try different shingles, metal, tile, slate and shake roofs in real colours, change the roof shape, and get a roof-area estimate.

Open it: https://alamjotsohal-creator.github.io/ridgeline-studio/

Open straight to a house: add `?a=` and the address, for example
https://alamjotsohal-creator.github.io/ridgeline-studio/?a=8%20Burlwood%20Road%2C%20Brampton%2C%20ON

Imagery © Esri, Maxar, Earthstar Geographics. Building outlines © OpenStreetMap contributors. Prices and measurements are consultation estimates; confirm on site.
